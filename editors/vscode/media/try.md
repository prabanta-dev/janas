# Ask it something

Open the chat of the extension you chose, pick the model whose name begins with **Janas** in its list of models, and ask a question. The answer comes from this machine: it works with the network off too.

**To have the code written into a file** (in Continue):

- **Apply** on a block of code in the answer puts it into the open file, as a change to accept or reject;
- **Ctrl+I** in the file (Cmd+I on a Mac): say what you want, and the change appears in the file itself;
- **Agent** mode, chosen under the chat's box: the model reads, creates and edits files by itself. It needs a model made for code, such as `qwen3-coder-30b-a3b`; a small model does it badly.

The status bar at the bottom shows **Janas** with a check while its servers are up. Click it for Janas's commands, among them **Show the engine at work**: speeds, the expert cache, where the time goes.
