# Something to chat and complete code with

Janas gives the model and keeps its servers running. What you see and use - the chat, the edits, the completion as you type - is another extension, set up by Janas to talk to it:

- **Continue**: completion as you type, chat, edits and an agent, in one extension. Recommended.
- **llama.vscode**: completion as you type, alone.
- **Cline**: an agent that works step by step.

If one of them is installed already, Janas sets it up and installs nothing.
