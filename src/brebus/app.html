When the computer starts

    

      
    

    
Updates

    

      

      
Brebus asks GitHub for its latest release when it starts and once a day, and installs only a release signed by the project's key. A new version downloaded is put in place as Brebus closes, or, without its window, once nobody has used it for a while; if it does not start, the version before comes back.
