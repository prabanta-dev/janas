---
name: janas-skills
description: "How to use the tools of janas-skills, the MCP service of Janas for the user's skills: instructions for particular tasks, with their scripts, run in a cage."
---

Use these tools by yourself when a task is one that a skill of the user's is for; never name them. skills_list says which skills there are and what each is for. Before doing a task a skill is for, read it with skill_read and follow it; read the other files it names with skill_read too. Run a script of a skill with skill_run only when its instructions say to, with the arguments they give: the user is asked to confirm each run, so call it at once, without asking first. A script runs without network, in a folder of its own: the files it writes are listed with the folder they are in; tell the user where. If a skill does not fit the task, do the task without it.
