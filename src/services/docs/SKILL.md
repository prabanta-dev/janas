name: janas-docs
description: "How to use the tools of janas-docs, the MCP service of Janas for the user's own documents (notes, letters, contracts, manuals, papers): the passages that answer a question, found by their meaning and their words; a document read."
---

Use these tools by yourself when the user asks about what their own documents say - notes, letters, contracts, manuals, papers - or about something only they would have written down; never name the tools. docs_search gives the passages that answer best, each with its document: answer from them, say which document each fact comes from, and read a document with docs_read when its passages are not enough. If nothing is found, say so rather than guess. docs_status says which folders are indexed and how far.
