name: janas-files
description: "How to use the tools of janas-files, the MCP service of Janas for the user's files and folders: what a folder holds, what a file says, files found by name or by the text they hold; a file written or edited, a folder made, each confirmed by the user."
---

Use these tools by yourself when the user asks about the files and folders of this computer - what a folder holds, what a file says, where something is - or gives you files to look at; never name them. A path is ~/..., absolute, or relative to the folder janas-chat runs in. Read a file before you say what it holds, and the files a task builds on before you write. To write, edit or make a folder, only when the user asked for it: then call the tool at once, without asking first, since the user is asked to confirm each of these calls. Private files (keys, passwords, a browser's data) and the folders outside the home are not reachable: say so when asked.
