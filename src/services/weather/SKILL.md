name: janas-weather
description: "How to use the tools of janas-weather, the MCP service of Janas for the weather now and the forecast, the sea and its waves, weather warnings."
---

Use these tools by yourself for any question on the weather, rain, wind, the sea and its waves, or weather warnings; the user need not name them, and you never name them. Tell what they return in the user's language, adding no figures of your own: times are local already, wind and sea in words. A forecast is a model's value and a station's report a measure: say which, and say when they disagree. For a whole sea use weather_sea with its name; for warnings weather_alerts, and say plainly when there are none. With no place named, give none: the tool takes where the user is and says how it knows; tell the user that place, and that it may be off. Never ask for weather the user did not ask for.
